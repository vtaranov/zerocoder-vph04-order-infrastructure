Учебный проект · VPh04

Инфраструктура сайта обработки заказов

Виктор Таранов

Серверная основа для будущего приложения: Nginx, PostgreSQL, pgAdmin, Docker Registry и Watchtower.

  • Открыть pgAdmin - вход с отдельной учётной записью.
  • Docker Registry API - требуется авторизация; ответ 401 без пароля ожидаем.
  • PostgreSQL доступен только внутри сети Docker.
  • Watchtower обновляет только явно отмеченные контейнеры учебного проекта.

Этот этап готовит инфраструктуру. Форма заявок и backend будут реализованы в следующих частях кейса.
